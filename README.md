# Создание сайтов · Евгения Даныева

Переносимый сайт с SVG-анимацией. Готовые статические файлы находятся в docs/.

## Локальный запуск

`python3 -m http.server 8080 --directory docs`

Проверка: `npm run check`. Установка зависимостей и сборка не нужны.

## GitHub Pages

В Settings → Pages выбрать Deploy from a branch, ветку main и папку /docs. HTTPS включается на GitHub Pages.

## Обновление

Редактируйте docs/index.html, docs/styles.css и docs/app.js. Контакты находятся в docs/config.js и семантических ссылках HTML. Описание медиа: docs/asset-manifest.json. Бриф, сцены, происхождение материалов и отчёт проверки находятся в documentation/.

Форма подготавливает сообщение локально. Посетитель копирует его и самостоятельно отправляет в MAX. Платные генерации и звук не использовались.
